## Project Aim Statement

This project aims to develop and evaluate a Retrieval-Augmented Generation (RAG) chatbot, based on the Walert framework, that provides RMIT students with accurate, source-grounded answers to university-related queries.

## User Stories

- As a **student**, I want to **ask questions in plain English and get accurate answers sourced from official university documents**, so that **I don't have to manually search through handbooks, policies, and FAQs to find what I need.**
- As a **university staff member**, I want to **reduce the volume of repetitive student queries handled manually**, so that **staff time can be redirected toward more complex student support needs.**
- As a **developer on the team**, I want to **evaluate retrieval accuracy and answer relevance against a benchmark dataset**, so that **we can objectively measure whether the RAG system is actually improving over a baseline.**
- As a **new student unfamiliar with university systems**, I want to **receive answers with cited sources**, so that **I can trust the information and verify it myself if needed.**
